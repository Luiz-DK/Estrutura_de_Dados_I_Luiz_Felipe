📖 Sobre o Repositório

Este repositório contém as atividades práticas da disciplina de Estrutura de Dados I, desenvolvidas utilizando a linguagem Go (Golang).

As atividades têm como objetivo aplicar, de forma prática, os conceitos estudados em sala de aula, utilizando Git e GitHub para versionamento, organização e entrega das soluções ao longo do semestre.

O repositório será utilizado durante todo o semestre, mantendo na branch main o histórico acumulado das atividades concluídas.
